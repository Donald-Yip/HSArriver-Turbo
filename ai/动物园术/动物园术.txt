============================================================
一、卡组定位与总策略
============================================================

核心计划：
- 前期用低费随从把每回合法力水晶转成场面，尽量每个回合都有东西站住。
- 靠群体增益（续连熵能/漂浮教程/庭审+3+3）与铺场数量压死对手，而不是靠单张大哥。
- 中期用腐蚀者扎卡兹给手牌/牌库随从减费，打出一波“超展开”；污亵负责返场。
- 制胜回合常常是：先铺 → 续连熵能/漂浮教程 → 全队交换或打脸；
  或者灾毁迅疾幼龙（牌库有“时空撕裂”时）一回合拍出 2 个 5/5 突袭。

关键资源（必须在卡组上下文里追踪，见第六节）：
- tears_in_deck：牌库中“时空撕裂”（TIME_025t）的数量。
  * 由续连熵能、暮光时空跃迁者洗入；由灾毁迅疾幼龙战吼消耗；抽到时自动施放。
  * 每张撕裂抽到时对我方英雄造成 3 点伤害；也是幼龙战吼的“弹药”。
- herald_count：本局已触发“兆示”的次数（暗誓信徒的战吼）。
- ritual_pending：挂起的克苏恩仪式（BE_726）数量与触发回合。
- summon_ritual_pending：挂起的召唤仪式（BE_085）数量与触发回合。
- trial_pending / trial_effects：挂起的黑幕庭审（CAP_405 系列）与选中的两个效果。
- 临时牌不走上下文：咒怨之墓（TLC_451）发现的牌本回合不打就消失，
  靠手牌实体的来源牌认（日志 LAST_AFFECTED_BY 解析成 created_by，等于 TLC_451；
  另兼容 Power.log 的 TEMPORARY tag）。评分直接读手牌，不需要 temporary_cards。

状态特征（评分要用到）：
- lethal_now：本回合存在确定斩杀。
- lethal_next_turn_estimate：按敌方当前场攻 + 手牌直伤估算的下回合最大伤害。
- 我方生命值（决定撕裂/庭审/自伤类牌的折扣）。

优先级硬规则：
1. 若本回合存在确定斩杀，优先选择斩杀线；不要为了铺场放弃斩杀。
2. 若对手随从下回合会形成确定斩杀，优先处理危险随从或建立足够阻挡。
3. 不要把增益牌用在即将被无收益交换、必死于已知效果或无法攻击且没有持续价值的目标上。
4. 不要仅因剩余法力为 0 就奖励一个低价值动作；先比较不同出牌顺序产生的最终场面。
5. 需要区分“本回合打出随从”与“本回合获得有效场攻”：刚召唤且无冲锋/突袭的随从
   通常不能立即攻击英雄。
6. 铺场卡组的“宽”本身就是价值：每多一个能动的随从 +3 分（BOARD_PRESENCE_SCORE），
   但被敌方一张群体伤害全清时，这个价值会反向放大，所以对局面上限要有估计。
7. 延迟牌（克苏恩仪式/召唤仪式/庭审）在“对手下回合可能斩杀”时价值大幅下降，
   不能按满额算。

二、单卡清单与评分
============================================================

说明：
- 评分框架与快牧一致：rankState = rankStaticState（场面分） + rankActions（最后一个动作的增量分）。
- 本节的“评分思路”都是动作增量分（除非特别写明“静态分”）。
- 数值是初始建议，可按胜率调参。

[2x] (0) 咒怨之墓
card_id: TLC_451
类型: 0 费法术（邪能），史诗
效果文字: 从你的牌库中发现另一张牌，将其变为临时卡牌。
评分思路:
  基础 +4（0 费换一张牌，过滤牌库）。
  +2：本回合是第一个动作（后面还有法力把发现的牌打出去）。
  -3：本回合已经打过别的牌才用它（临时牌可能没法力打出）。
  -3：手牌 ≥9（发现牌可能爆牌）。
  -100：打出时剩余法力为 0（发现的临时牌这回合打不出去，等于白扔咒怨之墓）。
        用户 2026-10-24 标注 t008-s2：0 法力时宁可直接结束回合。
  -12：打出后只剩 ≤2 费（发现的临时牌基本付不起，这一手大概率白费）。
       用户 2026-10-28 统一口径：咒怨之墓与栉龙的“低法力出牌”都扣 12。
  -20：手牌里还有 3 费及以上、本回合付得起且出得去的牌。
       判断用“打出咒怨之墓那一刻”的手牌与法力：评分拿到的 state 是序列末尾
       的场面，后面的出牌已经把法力花掉、牌也离开了手牌，必须加回来。
       用户 2026-10-23 标注 t006-s0：咒怨之墓一般是手牌没有太好的选择
       或者想找特定的牌时再出。
  动作分：本回合把刚发现的临时牌打出去 +20（CRYPT_TEMP_PLAY_BONUS）。
        这 20 分只补静态分看不到的“不打就没了”，身材/关键字仍由最终场面分算。
        留在手里不再扣分（用户 2026-10-28：扣分改加分，更简洁）。
  发现菜单（discover）来自咒怨之墓时，本回合付得起的选项再 +12
        （CRYPT_CASTABLE_BONUS）：付不起的临时牌选来等于白扔一次发现。
        原来这里是 -30，2026-10-28 按用户要求统一改成正向加分；
        付不起的选项直接按 0 计（回合末就丢，拿不到手），不再扣分。

[2x] (1) 不稳定的原型机
card_id: BE_207
类型: 1 费 0/1 机械，稀有
效果文字: 复生。亡语：使你手牌中的所有随从牌获得+1/+1。
评分思路:
  基础 +1（0/1 身材）。
  亡语按手牌随从数 N 计：+2N（N 上限按 4 算，最多 +8）；
  复生意味着亡语可触发第二次，若判断它会被交换两次，再 +1（简化：不再翻倍）。
  -1：手牌没有随从（亡语空放）。
  -2：上场后本回合还要连续铺场、它会被白吃（对手有 0/2 以上随从时）。
  评分区间：+1 ~ +9。
  出牌顺序/站位（2026-10-23 用户确认）：
  手里还有本回合付得起的暗誓信徒时先出信徒，原型机放最右（士兵右边），
  故意让士兵在回合结束吃掉它，触发亡语给手牌随从 +1/+1；
  法力只够出原型机时则照常直接出，不空过。

三、通用动作评分规则
============================================================

A. 铺场价值（静态分）
- 每点攻击 2 分、每点生命 1 分，双方对称（敌方取负）。
- 关键字：嘲讽 +2、复生 +5、圣盾 +2、突袭 +2、吸血 +3、剧毒 +3、潜行 +1。
- 每个友方随从额外 +3（BOARD_PRESENCE_SCORE），铺场卡组吃的就是数量。
- 双方英雄每点生命各 1 分（我方加、敌方减）。
- 静态分里对撕裂计数扣分：tears_in_deck × 2.0；我方生命 ≤15 时 × 1.5。
- 临时牌（咒怨之墓刚发现的牌）不再有静态扣分：留在手里不扣分，
  本回合打出去按动作分 +20（见单卡“咒怨之墓”）。
- 敌方场上一个随从都没有时 +1（ENEMY_EMPTY_BOARD_BONUS，用户 2026-10-28）。
- 终局敌方英雄生命归零 +1000（LETHAL_BONUS）：斩杀由终局场面统一判定，
  不管伤害来自单卡、攻击还是多张牌累计（用户 2026-10-28）。
- 关键随从站在场上额外加成：灾毁迅疾幼龙 +3（下回合突袭威胁）、
  腐蚀者扎卡兹 +2（减费光环已生效过，不再重复计算）。

B. 交换与打脸
- 交换能消灭对手高威胁随从并保住己方随从：+2 至 +10。
- 用高价值随从去换低威胁随从且无战术收益：-2 至 -4。
- 对手随从有嘲讽时，必须按合法攻击目标模拟。
- 若本回合可斩杀，打脸/直伤/攻击顺序要进行完整搜索，确定斩杀优先。
- 未斩杀时，打脸与交换应比较：未来场攻收益、对手下回合威胁、己方随从存活价值。
- 铺场卡组额外规则：能用 1/1 换掉对手 2/2 以上随从时，交换分 +2（赚身材）。

C. 斩杀与防斩杀
- 对每个可行动作序列计算本回合最大伤害，包括随从攻击、英雄攻击、法术直伤与效果触发。
  （本卡组主要是场攻 + 污亵 + 幼龙突袭；没有冲锋/直伤法术。）
- lethal_now = True：对非斩杀路线给予极大惩罚（-1000），但确保斩杀计算准确。
- 若对手下回合可能斩杀：优先移除关键攻击者、增加有效阻挡或迫使对手交换；
  此时延迟牌（克苏恩仪式/召唤仪式/庭审）动作分 -3。
- 不要把“理论场攻”当作本回合伤害；必须考虑召唤失调、嘲讽、冻结、攻击次数和目标限制。
- 嘲讽随从的阻挡价值按“能挡掉的敌方攻击点”估算，而不是固定 +1。

E. 顺序修正（单动作框架下的小补丁）
- 有增益牌（续连熵能/漂浮教程/庭审+3+3）时：先铺随从再增益，
  增益动作 +2；反之（先增益后铺）不加分。
- 咒怨之墓若不是本回合第一个动作，-3（见单卡）。
- 暗誓信徒若不是本回合最后一个随从，-2（士兵会吃掉后出的随从）。
- 攻击之后还跟着出牌动作：整条序列 -6（先把法力转成场面，攻击放最后；
  2026-10-23 用户标注 t006-s0：3 费回合先出教父卡扎库斯，而不是先攻击再出牌）。

六、代码实现约定（下一阶段用，不在本文件写代码）
============================================================

1. 评分入口与快牧一致：
   rankState(state, actions) = rankStaticState(state) + rankActions(state, actions)
   rankActions 只看 actions[-1]；顺序修正用 rankActions 里已有的 actions 列表做小补丁。

2. 新建卡组上下文 dongwuyuanshu_context.py（继承 search.ai_state.DeckContext），
   至少包含：
   - tears_in_deck: int           # 已洗入未抽到的时空撕裂数
   - tears_drawn: int             # 已抽到并自伤的次数
   - herald_count: int            # 已触发兆示次数
   - ritual_pending: int          # 克苏恩仪式挂起数量
   - summon_ritual_pending: int   # 召唤仪式挂起数量
   - trial_pending: bool          # 庭审是否挂起
   - trial_effects: tuple         # 选中的两个庭审效果 card_id
   - trial_due_turn: int          # 庭审触发回合
   （临时牌不放进上下文：按手牌实体的 created_by == TLC_451 直接认）
   钩子（真实对局 + 搜索模拟都要走，且在 copy() 出来的分支上推进）：
   - on_card_played(card_id)
   - on_card_drawn(card_id)（TIME_025t 抽到时 tears_in_deck -= 1，tears_drawn += 1）
   - on_turn_start(turn)（结算到期的仪式/庭审/临时牌清理）
   - on_minion_died(card_id)（可选：记录被士兵吃掉的随从）

3. 卡牌属性表 CARD_ATTRIBUTES（search 的目标推断依赖它）：
   本卡组只有 漂浮教程 BE_094 需要目标（友方随从）；
   其余法术与随从都不需要目标；庭审效果/克苏恩技能通过选择菜单触发，不进入
   possible_targets。庭审三张时长牌（CAP_405tb1~3）是从手牌打出的法术，不需要目标。

4. 选择菜单：用 general_choice_cards 提供的 card_id 查第四节表；
   查不到的策略按 0 分处理，并保证不会卡住（宁可随机选一个）。
   克苏恩技能菜单若无法识别，按快牧的做法给 -100 惩罚，宁可不打仪式。

5. 搜索模拟的延迟效果：不要求真的在搜索里推进 2 回合，延迟牌只按折现分计入；
   但 tears_in_deck / herald_count / 临时牌要在模拟分支里正确增减（幼龙战吼、
   咒怨之墓发现）。

6. 日志/调试：每次评分打印 card_id + 中文名 + 分项，便于复盘伏笔（沿用现有标注系统）。
