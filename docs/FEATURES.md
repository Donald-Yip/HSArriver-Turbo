# 功能目录

按「能干什么」分组，每条后面是入口。入口有三种：网页控制台（`http://127.0.0.1:8765`）的卡片、命令行 `hsctl`、右上角日志浮窗的按钮。

详细用法见 [README](../README.md) 与 [CLI.md](CLI.md)，这里只做索引。

---

## 一、打一局

| 功能 | 说明 | 入口 |
| --- | --- | --- |
| 状态机主循环 | 主界面 → 选套牌 → 换牌 → 对局 → 结算 → 回主界面，循环到停止 | 网页「开始对战」／`hsctl start` |
| 开始运行（准备） | 只开浮窗、把炉石切到前台，不开打；就绪后再点一次「开始对战」才真打 | 网页「开始运行」／`hsctl prepare` |
| 自动出牌 | 截取炉石盒子（HSAng）的 AI 推荐，OCR 出动作后校验合法性再点。支持随从交换、法术指定目标、英雄技能、地标、发现、抉择、交易、星舰发射、回溯 | 同上 |
| 自动换牌 | 换牌阶段按盒子推荐留牌，识别失败会重试并有独立延时 | 同上 |
| 自动进对战 | 拉起炉石 → 等主界面可点 → 点「传统对战」→ 选第 N 个卡组 | `hsctl enter-battle` |
| 快速选卡组 | 不进状态机，直接点第 N 格，秒级 | `hsctl deck-click N` |
| 卡组序号 | 配置自动选哪一格（1–9）| 网页「基础配置」／`hsctl deck N` |
| 模式切换 | 狂野／标准／休闲，按固定坐标点三个盾牌 | `hsctl mode wild\|standard\|casual` |
| 战绩统计 | 每局结束记胜负，算胜率，浮窗与网页同步显示 | 自动 |
| 手动接管 | 不进自动出牌：把当前对局状态打到终端，人工逐条输入动作（出牌、攻击、技能、结束回合）| `python main.py`（不走控制台的原始入口）|

## 二、启停与定时

| 功能 | 说明 | 入口 |
| --- | --- | --- |
| 立即停止 | 立刻终止自动化 | 网页「立即停止」／`hsctl stop` |
| 本局后停止 | 打完当前这局再停，不弃局 | 网页按钮／浮窗按钮 |
| 急停 | 叫停正在执行的「进对战／等界面」点击循环并停止自动化 | `Ctrl+Q`／`hsctl cancel` |
| 定时任务 | 指定开始与结束时刻，到点自动开始、到点收工 | 网页「定时任务」／`hsctl schedule` |
| 段位目标 | 打到设定段位（含等级）就停 | 网页「段位目标」／`hsctl rank-stop` |
| 命令队列 | 一次提交多条命令，控制台按顺序执行 | `hsctl queue` |

## 三、认输

| 功能 | 说明 | 入口 |
| --- | --- | --- |
| 自动投降（胜率） | 盒子 AI 胜率低于阈值且连续 N 回合都低 → 认输进下一局 | 网页「自动投降」／`hsctl concede` |
| 卡组识别投降 | 配多套「特征牌 + 且／或／非」条件树，命中任意一套立刻认输。只判**对方**，打出、亮出、开局生效卡都算，对手回合也判 | 网页「卡组识别投降」／`hsctl surrender` |
| 手动投降 | 对战中随时点「齿轮 → 认输」，不用先停自动化 | `hsctl concede now` |
| 名字校验 | 对局里玩家名与配置不一致（敌我识别反了）时暂停并告警一次 | 自动 |

## 四、重启与自愈

| 功能 | 说明 | 入口 |
| --- | --- | --- |
| 重启炉石 | 结束 Hearthstone.exe、清空日志目录（保留 Log.config）、重新拉起，**以认到主界面为准**才返回成功 | 网页／浮窗「重启炉石」／`hsctl restart-hearthstone` |
| 中断重启（看门狗） | Power.log 超过设定秒数不更新 → 重启炉石 + 重开一局，带次数与时间窗限制 | 网页「中断重启」／`hsctl watchdog` |
| 存活检测 | 每轮确认进程是否还在、对局中日志是否还在更新；判死即告警并停止，不空转 | 网页「存活检测」／`hsctl liveness` |

## 五、界面识别与坐标

| 功能 | 说明 | 入口 |
| --- | --- | --- |
| 坐标换算 | 客户区坐标（基准 1920×1080）↔ 屏幕坐标的唯一出口，DPI 感知，窗口移动后缓存自动失效 | 代码内 `display_mapping` / `window_tracker` |
| 截图区域清单 | 脚本要截的每一块（ROI）与判定点集中管理 | `screen_regions.py`／`hsctl regions` |
| 区域框预览 | 截一帧并把所有 ROI 框画在图上，不点击 | `hsctl regions`／`hsctl screenshot --points` |
| 校准 | 屏幕上拖框，把 8 个 ROI 与 4 个模式点击点对齐 | 网页／浮窗「校准」 |
| 界面识别 | 认出主界面（「传统对战」可点）与选套牌界面（「选择套牌」标题） | `hsctl ui` |
| 模板学习 | 站在界面上重裁识别模板，不用手改图片 | `hsctl ui --learn` |

## 六、配置与手感

| 功能 | 说明 | 入口 |
| --- | --- | --- |
| 单一配置源 | `ui_config.json`，大部分项目改完即时生效，不用重启 | `hsctl config` |
| 延时设置 | 换牌、出牌、点击前后的等待，支持运行中热改 | 网页「延时设置」／`hsctl delays` |
| 活人感 | 出牌后随机停顿、悬停手牌与随从，降低机械特征 | 网页「活人感」／`hsctl human-like` |
| 账号与日志目录 | 填自己的 BattleTag 与炉石日志目录 | 网页「基础配置」 |

## 七、控制台与接口

| 功能 | 说明 | 入口 |
| --- | --- | --- |
| 网页控制台 | 单页，零前端依赖，后端只跑标准库 HTTP | `hsctl serve start` 后开 8765 |
| 日志浮窗 | 置顶半透明小窗：实时日志、战绩、启动／停止、重启炉石、校准、保存日志 | 网页「日志浮窗」／`hsctl overlay on` |
| 命令行 | 30 余条命令，覆盖上面全部功能；`repl` 可进交互模式省掉重复敲 `hsctl` | `hsctl --help`／`hsctl repl` |
| HTTP 接口 | GET 读状态/日志/自检/查卡，POST 改配置/发指令；`--json` 输出供 agent 调用 | 见 `web_ui.py` 路由表 |
| 提权托管 | 借计划任务以最高权限常驻（鼠标注入需要），支持自停与状态查询 | `hsctl serve start --via-task` |
| 自诊 | 一条命令查解释器、依赖、控制台、提权状态，并给出下一步该跑什么 | `hsctl doctor` |
| 环境固定 | 把本机合格的 Python 解释器写进 `log/env.json`，换机器/换 agent 不用再猜 | `hsctl env --pin <path>` |

## 八、辅助工具

| 功能 | 说明 | 入口 |
| --- | --- | --- |
| 环境自检 | Python 版本、依赖包、运行环境是否满足要求 | 网页「环境自检」／`hsctl selfcheck` |
| 卡牌库 | 本地 `cards.json` 离线查卡：中文名补全、错字纠正（阿莉扎娜 → 阿扎莉娜）、同名多版本合并、排除酒馆/乱斗/冒险卡 | `hsctl card <中文名>` |
| 脚本日志 | 统计对战日志与运行日志的体积、打开所在目录、一键清理 | 浮窗日志区 |
| 实时日志 | 网页底部滚动日志；命令行可跟随 | 网页「实时日志」／`hsctl log -f` |
| Power.log 定位 | 自动找最新一次炉石会话的日志文件 | 代码内 `power_log` |
| 回归测试 | 1300 余项，覆盖坐标、日志解析、规则求值、网页接口与前端往返 | `python -m unittest discover -s tests -t .` |

## 文件分工

| 文件 | 职责 |
| --- | --- |
| `hsctl.py` | 命令行入口，本质是 web_ui 的客户端 |
| `main.py` | 不走控制台的原始入口：终端交互打牌 + Ctrl+Q 退出 |
| `web_ui.py` | HTTP 服务、路由、所有 API 与后台线程 |
| `web/index.html` | 控制台页面（HTML + CSS + 原生 JS 单文件） |
| `FSM_action.py` | 状态机主循环、出牌决策、投降判定、存活与看门狗检查 |
| `src/` | 感知与执行细节：截图、OCR、推荐解析、换牌流、出牌流、校验、特殊牌型 |
| `battle_entry.py` | 界面识别、进对战、选卡组、重启后等主界面 |
| `log_state.py` | Power.log 解析成对局状态与实体表 |
| `surrender_rules.py` | 卡组识别投降的规则校验、对局事实跟踪、求值 |
| `card_catalog.py` | 中文卡名 ↔ cardId 索引与模糊匹配 |
| `config.py` | 配置的单一来源与分层合并 |
| `screen_regions.py` / `display_mapping.py` / `window_tracker.py` | ROI 清单、坐标换算、窗口位置跟踪 |
| `calibrate_roi.py` / `region_overlay.py` | 校准窗口与区域框绘制 |
| `log_overlay.py` | 日志浮窗 |
| `hs_restart.py` / `selfcheck.py` | 重启炉石、环境自检 |
| `manual_controller.py` | 手动逐条打牌 |
| `tests/` | 回归测试，含一个用假 DOM 跑前端脚本的往返用例 |
