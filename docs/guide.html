HSLegendArriver 安装与使用

从一台干净的 Windows 机器开始，到能正常挂机为止。

适用于 2026-10-17 之后的版本 · 命令都在 PowerShell 里执行 · 其它文档： README.md（全量说明）、docs/CLI.md（命令手册）、 docs/FEATURES.md（功能目录）

这是什么

一个自动打炉石的脚本。它截取炉石盒子（HSAng）给出的 AI 推荐，用 OCR 认出动作，再模拟鼠标点出去；同时读炉石的 Power.log 确认自己的操作有没有生效。所有功能既能在网页控制台点，也能用命令行 hsctl 发。

三个部件的关系：

部件干什么怎么开
控制台（web_ui.py）常驻后台，是唯一的状态源；网页、命令行、浮窗都只是它的客户端python web_ui.py
网页（http://127.0.0.1:8765）所有开关、参数、校准、日志启动控制台后自动打开
浮窗游戏画面右上角的置顶小窗：实时日志、战绩、开始/停止/重启炉石网页「日志浮窗」或 hsctl overlay on

装之前先确认

前提为什么
Windows + Python 3.12（64 位）OCR 后端 paddlepaddle 2.6.2 只有 3.12 及以下的轮子。装成 3.13 会「能启动、能点开始游戏，但一进对局就卡在换牌」
管理员权限启动游戏不接受普通权限进程的鼠标注入。不提权的现象是「脚本在跑，但点了没反应」
炉石窗口设成 1920×1080，然后校准一次窗口化就行，不必全屏：走「选项 → 图形 → 分辨率」把窗口固定成 1920×1080（和代码里的坐标基准一致）。唯一别用的是「最大化窗口」——客户区不是 1920×1080，坐标基准错位时法术指定目标会一直失败重试
项目路径不含中文OCR 与部分依赖对中文路径支持不好
炉石盒子开简体中文，左侧「打法参考A / 推荐打法」面板完整可见脚本截的就是这一块。被别的窗口挡住就识别不到
分辨率与缩放不限

4K 桌面配 150% 缩放也能跑：脚本按炉石客户区的实际几何实时换算所有坐标。屏幕分辨率与缩放都随意。

要固定的是炉石窗口自己的客户区 = 1920×1080：和代码里的坐标基准一致，盒子面板（固定像素的独立窗口）也不会被挤出去。窗口化、全屏都行，唯独别用「最大化窗口」。

改完尺寸后打开校准窗口拖一次（S 保存），之后只要不换尺寸、不换机器就不用再校准。

安装

  1. 装 Python 3.12

    到 python.org 下 Python 3.12，安装时勾上 Add python.exe to PATH。装完验证：

    python --version

    必须是 Python 3.12.x。如果显示 3.13 或别的版本，说明机器上有多个 Python——后面每条命令都要写 3.12 那个的完整路径（例如 C:\Python312\python.exe）。用 conda 的话：

    conda create -n HTL python=3.12 -y
conda activate HTL
  2. 装依赖

    在项目根目录打开 PowerShell：

    pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

    里面有 PaddleOCR 和 PaddlePaddle，首次要下几百 MB，慢是正常的。装完验证：

    python -c "import cv2, paddleocr, win32api, keyboard; print('ok')"

    打印 ok 就算齐了。

  3. 第一次启动

    用管理员 PowerShell（开始菜单搜 PowerShell → 右键 → 以管理员身份运行）：

    cd <项目根目录>
python web_ui.py

    浏览器会在 1 秒内自动打开 http://127.0.0.1:8765。端口被占用时会自动往后顺延（8765–8785），以控制台窗口打印的地址为准。

    验收：网页打开、「运行概览」有数据。这个 PowerShell 窗口别关，关掉服务就停了。

  4. 免 UAC 常驻（可选，建议做）

    每次手动开管理员窗口很麻烦，也没法手机远程。注册一次计划任务，之后普通权限就能拉起最高权限的控制台：

    # 管理员 PowerShell 里跑一次
python hsctl.py serve install-task

# 之后随时（普通窗口即可，不弹 UAC）
python hsctl.py serve start --via-task

    验收：python hsctl.py serve task-status 显示任务存在且勾了最高权限。

  5. 固定解释器（换机器 / 换 agent 必做）

    机器上 Python 不止一个时，别靠猜，让脚本自己找并记住：

    python hsctl.py env discover                        # 列候选，逐个校验版本与依赖，不写盘
python hsctl.py env pin "C:\Python312\python.exe"   # 选合格的存进 log/env.json
python hsctl.py --json doctor                       # 复验，verdict 应为 env_ok

    log/env.json 是本机专属配置，不进仓库。之后无论用哪个 Python 跑 hsctl，都会自动切到合格的那个解释器。

首次配置

打开网页，从上往下做这四件。

1. 填账号

「基础配置」→ 用户 ID：填当前战网的完整昵称，含 #编号，例如 异灵术#54321。

这一项填错，整局不出牌

脚本靠昵称区分「我」和「对手」。填错或不填，会把整局都当成对手回合，表现为一直不出牌。换账号一定要同步改。

2. 填日志目录

同一张卡片里填炉石的 Logs 文件夹，例如 D:\Hearthstone\Logs，点旁边的「检测」验证。

两个输入框失去焦点时会自动保存，不用找保存按钮；自动化运行期间不可修改。

3. 校准（只需一次）

「校准区域」卡片 →「打开校准窗口（屏幕上）」。一共 12 个目标：8 个截图区域 + 4 个模式点击点（模式按钮、狂野、标准、休闲）。

操作说明
对齐鼠标拖框。第一块是盒子「打法参考A」面板，拖对后提示条变绿并显示「已检测到盒子面板」
切换目标按 Tab，或直接点目标条里的一行
保存按 S，或点网页上「保存全部区域」（12 个一起存）
退出点「退出」或按 Esc

换分辨率、改窗口大小、换盒子皮肤之后要重新校准。窗口位置移动不用重新校准——框会跟着炉石窗口走。

4. 看环境自检

页面顶部「环境自检」每项一行：

✅达标
⚠️和推荐值不同，但还能跑
❌不满足，必须先修。缺依赖会直接给出 pip 命令

没有 ❌，安装部分就结束了。

其中「窗口化尺寸」这一项只在炉石窗口化时出现：✅ 窗口化 1920×1080 就是标准配置；显示 ⚠️ 窗口化 1600×900（基准 1920×1080） 表示还能跑，但建议把窗口改成 1920×1080 后重新校准。全屏时这一项不显示。

开始打

第一步：准备

点「开始运行（准备）」。它只做两件事：打开右上角日志浮窗、把炉石切到前台，不会自动开打。

检查浮窗状态行里的「账号」是不是匹配。不是的话回上一步改用户 ID。

第二步：开始对战

点「开始对战」（或浮窗上的同名按钮），二次确认后开打。

从按下到鼠标第一次动是 1–3 秒：先认「传统对战」/选套牌界面，再点卡组格，然后进换牌。日志里会有 [SYS] 进入对战 +x.xs：… 的阶段分解，慢的时候看这几行停在哪。

第三步：怎么停

方式什么时候用
Ctrl+Q任何时候按都能停，包括正在点「进对战」的过程中（热键注册在控制台进程里，控制台没跑时无效）
「立即停止」/ hsctl stop网页上点，立刻停
「本局结束后停止」手里这局还在打，不想弃
hsctl cancel和 Ctrl+Q 同一条通道，给命令行 / agent 用

浮窗上的按钮

按钮作用
开始对战 / 中止（恢复）开始或暂停自动化
本局结束后停止打完当前这局再停；再点一次取消
保存日志另存一份对战日志到 logs\
校准开 / 关屏幕上的校准窗口（和网页那个是同一个）
打开日志 / 清理日志用资源管理器打开日志位置 / 一键清掉脚本日志
重启炉石会先弹确认：停自动化 → 结束 Hearthstone.exe → 清空日志目录（保留 Log.config）→ 重新拉起，认到主界面才算成功

浮窗只移动鼠标、不点击，不会干扰出牌；标题行右侧有「最小化」可以把整个浮窗折叠成一条。

可选开关

默认关着的都不影响第一次跑通，按需要开。

卡片默认干什么
存活检测开每个循环确认炉石进程还在、对局中日志还在更新；判死立即告警并停止，不空转。日志停滞 120s 告警、300s 自动停止
中断重启关日志超过设定秒数（默认 300s）不更新 → 重启炉石 + 重开一局。默认 10 分钟内最多重启 3 次
自动投降（胜率）关盒子 AI 胜率低于阈值（默认 10%）且连续 3 回合都低 → 认输进下一局
卡组识别投降关认出对面是哪套卡组就立刻投，见下一节
段位目标关打到设定段位（或传说某名次）就停，不打断正在进行的一局
活人感关操作后用随机延时（0.5–3s），并在手牌区随手悬停；对手出新随从会移上去停一停。只移动鼠标，不点击
定时任务—设开始与结束时间；到点收工前会先等本局打完

两套认输

两个开关互相独立，任一命中都会投降，别混：

自动投降（胜率）卡组识别投降
触发条件盒子 AI 胜率持续偏低对面出现了你配置的特征牌（或满足你写的条件组合）
怎么配填阈值和连续回合数建「卡组库」，每套写若干特征牌，用「与 / 或 / 非」组合，可任意层嵌套
判谁全局状态只判对方：自己手里有同名卡永远不会触发
能否调试看浮窗「投降检测」行hsctl surrender check 列对方职业 + 每条条件的 ✓/✗

卡组识别投降的三条规则：

  • 「打出来」「亮出来」「开局生效的全局卡」都算数。裂魂者阿扎莉娜这类开局生效的卡永远打不出来，脚本从开局日志里抓。
  • 对手回合也判，对方一打出来就投，不用等自己回合。
  • 对局中热保存时，如果这套规则当场就能命中，会先问一次再写盘。

卡名直接打中文，会弹候选卡；写错字会自动纠正（阿莉扎娜 → 阿扎莉娜）。

一条命令先自诊

不知道该查哪儿时：python hsctl.py --json doctor。它一条命令回答环境对不对、控制台在不在跑、权限够不够，并直接给出下一步该跑什么。

文件都在哪

文件内容能不能手改
ui_config.json你的全部配置：账号、日志目录、延时可、各开关、校准坐标、投降规则建议通过网页改；手改要保证 JSON 合法
log/env.json本机合格的 Python 解释器路径（本机专属，不进仓库）用 hsctl env pin 写
log/ui_port.txt控制台端口、pid、自停 token别动，删了会影响停止/重启
ui_log_last.txt运行日志（超过 2 MB 自动裁到最近 800 行）可以删
logs\对战日志_*.txt浮窗「保存日志」另存的对战日志可以删；浮窗上有「清理日志」
炉石自己的 Logs\Power.log 等游戏日志「重启炉石」会清空它（保留 Log.config）

换机器 / 交给 agent

换机器只有一件事要做：把解释器固定到新机器上。

python hsctl.py --json doctor
python hsctl.py env discover
python hsctl.py env pin "<新机器上 3.12 的路径>"
python hsctl.py --json doctor     # verdict 应为 env_ok

交给本机 agent（WorkBuddy / DSH / Claude Code 等）时，最短闭环是四条：

python hsctl.py --json doctor     # 拿到 verdict + next_steps
# 照抄 next_steps 里的命令，把环境和控制台修好
python hsctl.py --json doctor     # 复验到 env_ok
python hsctl.py --json status     # 之后按需探活、干活
  • 命令一律加 --json：输出机器可读，错误也走 stdout，退出码可判断。
  • 退出码：0 成功 · 1 业务失败 · 2 参数错误 · 3 连不上控制台 · 4 本机没有合格的 Python 环境。
  • 控制台只绑 127.0.0.1，不做端口转发。
  • screenshot 只抓图返回路径；判断界面的活交给人，别让 agent 自己读图下结论。

命令速查

# 状态与自检
python hsctl.py --json doctor        # 一条命令自诊（会话第一条）
python hsctl.py status               # 阶段 / 账号 / 战绩 / 参数
python hsctl.py log -f               # 实时跟随日志
python hsctl.py selfcheck            # 环境自检

# 控制台
python hsctl.py serve start --via-task
python hsctl.py serve stop
python hsctl.py serve task-status

# 打一局
python hsctl.py prepare              # 开浮窗 + 切前台，不开打
python hsctl.py start                # 开打
python hsctl.py stop                 # 立刻停
python hsctl.py stop --after-game    # 打完这局再停
python hsctl.py cancel               # 急停（同 Ctrl+Q）

# 进对战 / 选卡组 / 切模式
python hsctl.py enter-battle --deck 6 --start
python hsctl.py deck-click 6         # 秒级快选第 6 格
python hsctl.py mode wild

# 认输
python hsctl.py concede now          # 手动投降（运行中可用）
python hsctl.py surrender            # 看卡组识别规则
python hsctl.py surrender check      # 这局的判定进度
python hsctl.py surrender on         # 打开总闸（off 关掉，卡组保留）

# 排查
python hsctl.py screenshot           # 抓一帧，返回路径
python hsctl.py ui                   # 现在在哪个界面
python hsctl.py regions              # 所有区域框画在图上
python hsctl.py card 神秘            # 查卡（本地，不联网）

完整参数见 docs/CLI.md，或 python hsctl.py --help。
