## ✨ 项目简介

**HSLegendArriver（传说到达者）** 是一个用于《炉石传说》的自动化打法执行器。

项目通过读取炉石对局日志，并结合 **炉石盒子「推荐打法」** 提供的推荐操作，自动识别当前对局状态并执行对应的鼠标点击与键盘操作。

简单来说：

> **炉石盒子负责告诉你"怎么打"，HSLegendArriver 负责帮你"打出去"。**

- 到 <https://www.python.org/downloads/> 下载 **Python 3.12** 安装包（非常重要，当前出现多个安装成3.14导致无法识别的朋友，如果你后续的分辨率都是设置正确，脚本可以正确点击开始游戏但是进入游戏后卡在换牌且AI识别都无法正常工作，必须检查当前python的版本是否为3.12！）；
- 安装时**务必勾选 "Add python.exe to PATH"**；
- 装完在 PowerShell 运行 `python --version` 验证。

## 🎯 校准截图区域（适配你本机盒子 UI 大小）

盒子「推荐打法」面板的位置/大小会随**盒子窗口大小、分辨率**不同而变化。首次使用或换了盒子窗口大小后，用校准窗口手动校准一次。

**三个入口打开的是同一个窗口**，不用记两套用法：

| 入口 | 怎么开 |
| --- | --- |
| 网页控制台 | 「**🎯 校准区域**」卡片里的 [📐 打开校准窗口（屏幕上）] |
| 日志浮窗 | 右上角浮窗点 **「校准」**（再点一次收起） |
| 命令行 | `python calibrate_roi.py` |

**三个可校准目标**（按 **Tab** 切换，或直接点屏幕左上角的目标条）：

| # | 目标 | 写入 `ui_config.json` | 怎么对齐 |
| --- | --- | --- | --- |
| 1 | 🟩 盒子推荐面板 | `recommendation_roi` | 把盒子面板顶部「**打法参考A**」红头区域框进绿框 |
| 2 | 🟦 换牌「确认」按钮 | `mulligan_confirm_roi` | 框住换牌界面里的「确认」按钮 |
| 3 | 🟧 盒子「AI胜率」浮动条 | `ai_win_rate_roi` | 框住左上角的「AI胜率 X%」浮动条（兜底区域自动跟着外扩） |

操作：

1. 打开校准窗口 → 屏幕上画出脚本实际使用的**全部截图区域**，当前目标用粗框 + 右下角**缩放手柄**标出，**屏幕正中央**是目标条，右侧是推荐区域的**实时 OCR 预览**；
2. 中间是准星（✛ 阶段判定点）、橙框、红细框这些参考框，颜色和含义与下表一致；
3. **拖框的边框**整体移动、**拖右下角手柄**调整大小；**Tab** 换下一个目标；
4. 按 **S**（或点目标条里的 [保存全部区域]）把三个区域一起写回 `ui_config.json`，**Esc** 退出；
5. 保存后**重开一局**生效（不覆盖名字/日志目录/延时等其它配置）。

> 目标条故意放在**屏幕正中央**：左上角压着盒子「AI胜率」浮动条（校准时得能看见它），顶部中间是「请对齐相应UI」提示条，正中才是空出来的地方。

> **框以外的画面是鼠标穿透的**：只有框/手柄/目标条上才拦鼠标，其余点击照常落到炉石上，可以边看游戏画面边调。
> 顶部提示条每 1.5 秒重判一次「绿框里有没有盒子面板」——变成绿色「已检测到盒子面板」就说明推荐区域对齐好了。

### 屏幕上那些框 / 点分别是什么

| 画出来的框 / 点 | 对应区域 |
| --- | --- |
| 🟩 绿框 | 盒子推荐面板（OCR 识别来源 `recommendation_roi`）—— 把「打法参考A」面板移进来 |
| 🟦 蓝框 | 换牌「确认」按钮区域（提交校验用） |
| 🟧 橙框 | 盒子「AI胜率」浮动条（自动投降用） |
| 🟥 红细框 | AI胜率兜底区域（主区域读不到时放宽再读一次） |
| ✛ 黄十字 | 阶段判定点（脚本靠这几个像素判断当前是主界面/选牌/对战中） |

<img width="1180" alt="校准窗口在屏幕上显示的截图区域框" src="docs/images/regions.png" />

> 图为示意图（假画面 + 真实叠加层），用来展示框的位置与提示条样式。

> 程序固定 **1920×1080、缩放 100%**，如需更大/更小的盒子窗口，重新拖框即可。

### 只跑命令行时

```bash
python calibrate_roi.py              # 正常校准（含推荐区域 OCR 预览）
python calibrate_roi.py --no-ocr     # 不加载 OCR 引擎，纯拖框
python calibrate_roi.py --selftest   # 自检：窗口打开约 1 秒自动退出
python calibrate_roi.py --target win_rate   # 打开时直接选「AI胜率」为目标
```

## 🖥️ 实时日志浮窗（右上角）

自动对局开始时，屏幕**右上角**会出现一个**置顶半透明**小窗（263×654），实时滚动显示自动化日志与当前状态：

<img width="320" alt="日志浮窗" src="docs/images/overlay.png" />

浮窗上的按钮（右下角都补齐一行，共 5 行）：

| 按钮 | 作用 |
| --- | --- |
| ▶ 开始对战 / ⏹ 中止（▶ 恢复） | 开始 / 立即停止自动化 |
| ⏸ 本局结束后停止 | 打完当前这一局再停；再点一次取消 |
| 校准 | 开/关屏幕上的校准窗口（与网页按钮同一个窗口） |
| 💾 保存日志 | 把对战日志另存一份 |
| ♻ 重启炉石 | **会先弹确认**：停自动化 → 强制结束 `Hearthstone.exe` → 清空日志目录内容（保留 `Log.config`）→ 重新启动炉石 |
| ✖ 退出浮窗 | **只关这个窗口**，脚本与自动化继续跑；回网页点「🪟 日志浮窗」即可再打开 |
| 🚪 退出脚本 | 停自动化并结束整个进程 |

> ♻ 重启炉石用于**日志状态和游戏对不上**的情况（例如明明没在游戏，浮窗却一直显示在换牌——
> 那是上一局残留的 `Power.log` 被当成了最新日志）。重启并清空日志后，点「开始对战」重新开始即可。
>
> 浮窗右上角贴着屏幕边缘，脚本的辅助点击点（激活后台炉石、取消右键）会自动避开它，
> 不会出现“鼠标跑到浮窗上点了一下”的情况。

## 🧪 环境自检

**第一次启动脚本会自动自检一遍**，之后随时可在网页顶部「🧪 环境自检」卡片点 [🔍 重新自检]。明细列表**可以收起**（点卡片右上角「收起」，选择会记在浏览器里；一旦有 ❌ 会自动展开，不会把问题藏起来）。

| 检查项 | 怎么判 |
| --- | --- |
| Python 版本 | 必须 **3.12 的 64 位**：装了别的版本（尤其 3.13/3.14）会直接判 ❌ 并给出建环境命令 |
| 依赖包 | 逐个 import 一遍，并和 `requirements.txt` 的版本比对；缺哪个直接给 `pip install` 命令 |
| 管理员权限 | 不是管理员 → 鼠标/键盘点击会被系统拦掉（现象就是「脚本在跑但点了没反应」） |
| 屏幕分辨率 / 缩放 | 必须是 **1920×1080 / 100%**，否则硬编码坐标会整体偏移 |
| 炉石窗口 | 没开只算 ⚠️（点「开始运行」会先拉起战网和炉石） |
| 炉石日志目录 | 目录不存在算 ❌；目录在但还没有 Power.log 只算 ⚠️（打一局就有了） |
| OCR 模型目录 | 没下载只算 ⚠️，首次识别会自动下载 |

结论会同时写进控制台日志（❌/⚠️ 逐条带修复提示），自动化出问题前的第一步排查就从这里看。

## ⚠️ 启动前检查

- [ ] 盒子推荐打法位于屏幕左侧
- [ ] 桌面 / 炉石分辨率均为 **1920 × 1080**，Windows 缩放 **100%**
- [ ] 炉石显示模式为 **全屏**（`设置 → 选项 → 显示`），**没有**使用「最大化窗口」
- [ ] 「用户 ID」填的是**当前账号的完整战网昵称（含 #编号）**——换过账号一定要同步改
- [ ] 网页「🧪 环境自检」里没有 ❌（Python 3.12、依赖、管理员权限、分辨率全绿）
- [ ] 打开「校准」窗口，确认盒子面板落在绿框内（提示条变成绿色「已检测到盒子面板」）
- [ ] 炉石盒子使用**简体中文**，左侧「推荐打法」完整显示
- [ ] 炉石 / 炉石盒子窗口未被其他窗口遮挡
- [ ] 使用**管理员权限**启动 Python，`HEARTHSTONE_LOG_ROOT` / `YOUR_NAME` 配置正确
- [ ] 「🩺 存活检测」保持开启（默认开启），避免炉石闪退后无人值守空转
