🕹️ 对战控制

🪄 点 「开始运行」只会打开日志浮窗、把炉石切到前台，不会自动开打；就绪后按钮变为 「开始对战」，再点一次（二次确认后）才真正开始。
⌨️ 快捷键 Ctrl+Q 可随时立即停止自动化；请保持炉石与炉石盒子前台可见、分辨率 1920×1080。
🖥️ 炉石请使用 全屏模式（设置 → 选项 → 显示 → 全屏），不要用「最大化窗口」：最大化时窗口坐标与 1920×1080 全屏不一致，硬编码的点击坐标会整体偏移——下随从因有吸附还能成功，法术指定目标则会一直失败重试。
♻ 浮窗上的 「重启炉石」会先弹确认，再执行「停自动化 → 强制结束 Hearthstone.exe → 清空日志目录（保留 Log.config）→ 重新启动炉石」，用于日志状态和游戏对不上（没在游戏却显示在换牌）的情况；重启会优先走战网（战网没开就先开战网，再点「开始游戏」），而且以游戏窗口出现才算成功，不会出现“报已启动、其实炉石已经关了”；「退出浮窗」只关窗口、脚本继续跑；关掉浮窗会回到未就绪状态（大按钮变回「🪄 开始运行（准备）」），再点上面的「🪟 日志浮窗」或「开始运行」把浮窗开出来，然后点「⚔️ 开始对战」才会开始。

🩺 存活检测（挂机防空转）

挂机时最怕“炉石已经没了，脚本还在对着失效画面做 OCR”。开启后每个循环都会确认：Hearthstone.exe 进程是否还在（闪退/被关，权威信号），以及对局中 Power.log 是否还在更新（进程还在但游戏卡死）。判定退出会立刻在日志与浮窗醒目告警并自动停止自动化，不会空转到天亮。默认开启；自动化运行中不可修改。
存活状态：等待检测…

🔄 中断重启（卡住自动重开）

开启后，自动化运行中只要 Power.log 停滞超过阈值（默认 300 秒 = 5 分钟）就判定炉石卡住，自动执行：重启炉石 → 等主界面 → 重新进入对战 → 重新开始挂机，无人值守也能自己爬回来。
⚠️ 与上面的「存活检测」不要同时依赖：本开关打开时，日志停滞交给它重启，存活检测那条「自动停止」不再触发；关掉则恢复原来的「停止并等人工」。
🛡️ 防无限重启：10 分钟内最多重启 3 次，超过就停止并醒目告警（反复重启说明不是一两次抖动，继续只会烧资源）。
⚠️ 只在自动化运行中判定——停在主界面发呆时日志本来就不动，不会被误重启。
中断重启：等待检测…

🏳️ 自动投降

检测左上角盒子「AI胜率」，连续 N 回合低于阈值时自动执行：右下角齿轮 → 中间红色「认输」。默认关闭，需手动开启；自动化运行中不可修改。
检测状态：等待自动化运行…

🎯 卡组识别投降（只判对方）

按「对方有哪些卡」识别对手卡组，命中就立刻投降。卡牌框里输入中文会弹出候选卡，点一下自动带出 ID。
每组可以选且 / 或 / 非并任意层嵌套，例如「A 且（B 或 C）」；点标题左侧箭头可把整套规则收起。
所有条件都判对方：我方有同样的卡绝不会触发；对方职业不参与以外的判断也只在卡组上写。
表单支持多层「且 / 或 / 非」；表单表达不了的字段（如 turn、card_type、at_least）会标成「高级」并原样保留。
状态：等待自动化运行…

🏁 段位目标（可选）

判定点：只在「选择套牌」界面读一次右上角名次（读到的数字就是传说名次，未上传说时该处空白）。
达到后停止：名次数值 ≤ 目标 → 本局结束后停止自动化（不中断正在进行的一局）。
控分：名次数值 < 目标（名次比目标更靠前）→ 开局即投降，把名次往后压，压到不超目标就恢复正常对战；单次运行最多投降 40 局。
提示：炉石传说里数值越小名次越高。默认关闭；自动化运行中不可修改。
段位目标：等待自动化运行…

🎭 活人感（可选）

启用：活人感总开关。看卡牌：每次操作结束后不再用固定的「操作后延时」，而是先随机等 0.5~3 秒（可调），等待期间鼠标在手牌区像真人一样随手停一停（每处 0.2~1 秒，可调）；关掉它连这段随机延时一起取消，回到固定延时。看随从：对手场上出现新随从时，鼠标移到该随从上随机悬停 0.2~1.5 秒（可调，只在对手回合，一次最多 3 个）。全程只移动、绝不点击，不影响出牌判定；每段悬停结束都复位到左上角。默认关闭；自动化运行中不可修改，下一局开始时生效。

🎯 校准区域

📐 校准窗口：自动化没在跑的时候打开，屏幕上显示当前目标那一个框（非当前目标不画，屏幕上不会全是框）+ 屏幕正中央的目标条 + 右侧推荐区域实时 OCR 预览，并提示「请对齐相应UI」。12 个目标都能拖、都能存：1 盒子推荐面板、2 换牌确认按钮、3 AI胜率浮动条（AI胜率兜底区域自动跟着外扩）、4 结算「开始」按钮（用框中心点击）、5 段位数字、6 主界面「传统对战」、7 选择套牌「选择套牌」标题、8 选择套牌 9 个卡组、9~12 四个模式按钮/盾牌（狂野/标准/休闲，框中心=点击点）。Tab 切换目标、抓框正中央的四向箭头十字标整体拖动（拖四条边也行，就是不好抓）、拖右下角手柄缩放、抓目标条标题带 ✥ 可把整张目标条拖开（目标行和按钮仍照常点；挪动只在本次打开期间有效，下次回屏幕正中）、S 保存（写入 ui_config.json，不覆盖名字/日志目录/延时）、Esc 退出。框以外的画面保持鼠标穿透（✛ 阶段判定点是只读参考，点不到炉石的地方照常点得到）。保存后点一次「开始对战」即生效，不用重启脚本。
🧲 拖动/缩放炉石窗口时五个框会实时跟着走：坐标存的是「客户区相对位置」，校准一次之后窗口随便挪都不用重新校准。
🖱️ 框以外的画面是鼠标穿透的：只有框/手柄/目标条上才拦鼠标，其余点击照常落到炉石上，可以边看游戏画面边调。顶部提示条每 1.5 秒重判一次「绿框里有没有盒子面板」，对齐好了会变绿。
🧭 右上角日志浮窗的 「校准」 按钮打开的是同一个窗口（再点一次收起），三个入口不用记不同的用法。
